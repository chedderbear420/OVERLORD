# Calibration Lab

The calibration lab evaluates whether model probabilities and edge estimates deserve trust.

## Inputs
- MarketState history.
- Features.
- Labels.
- Model probability outputs.
- EdgeSignal records.
- Replay traces.
- Paper ledger entries.

## Reports
- Calibration curves.
- Brier score.
- Log loss.
- Expected value versus realized value.
- Edge bucket performance.
- Drift and regime diagnostics.
- Strategy scorecards.

## Promotion Rule
Machine learning cannot be promoted until clean data, labels, replay results, and calibration reports exist.
