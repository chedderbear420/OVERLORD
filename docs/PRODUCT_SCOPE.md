# Product Scope

Overlord is a research operating system for Kalshi sports prediction markets. It is built to identify, explain, replay, and score short-horizon mispricing candidates before any live execution is considered.

## In Scope Now
- Repo constitution and safety rules.
- Planning documents.
- Repo-scoped Codex skills.
- Architecture for recording, normalization, replay, paper trading, calibration, risk governance, and audit.

## Explicitly Out of Scope Now
- Live trading.
- Autonomous order placement.
- API key files or secret material.
- Kalshi connectivity.
- MiroFish integration.
- OpenClaw integration.
- Copying external repository source code.

## Success Standard
Overlord must prove that a candidate edge survives market price, fees, spread, slippage, liquidity, uncertainty, replay evidence, calibration history, and risk limits. Winning predictions alone are not sufficient.
