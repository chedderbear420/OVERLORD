# Open Source Research Notes

Overlord may study public concepts and documentation, but it must not copy external repository source code.

## Allowed
- Reading official documentation.
- Summarizing concepts in original words.
- Recording citations for future review.
- Comparing architecture patterns at a high level.

## Not Allowed
- Copying external repo source code.
- Importing third-party code without license review.
- Adding unreviewed trading logic from outside projects.
- Treating open-source agents as trading authorities.

## Current Note
OpenClaw and MiroFish are future boundary topics only. They are not integrated in the current phase.
