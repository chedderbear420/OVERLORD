# OpenClaw Boundary

OpenClaw is a future operator/assistant layer, not the trading brain.

## Allowed Future Role
- Surface dashboards and alerts.
- Help operators inspect evidence.
- Draft summaries and checklists.
- Request manual confirmation in future approved phases.

## Forbidden Role
- No autonomous live trading.
- No risk override.
- No permission bypass.
- No hidden order placement.

## Current Phase
Do not integrate OpenClaw yet. This document only defines the boundary.
