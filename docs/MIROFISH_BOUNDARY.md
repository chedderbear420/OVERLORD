# MiroFish Boundary

MiroFish is an optional future narrative simulation adapter.

## Allowed Future Role
- Provide scenario narratives.
- Help describe game context.
- Generate hypotheses for research review.

## Forbidden Role
- Not a truth engine.
- Not a price authority.
- Not a trading authority.
- Not allowed to override replay, calibration, risk, or permissions.

## Current Phase
Do not integrate MiroFish yet. This document only defines the boundary.
