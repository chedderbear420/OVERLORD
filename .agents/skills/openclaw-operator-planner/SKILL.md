# OpenClaw Operator Planner

## Purpose
Plan the future OpenClaw operator boundary without giving it trading-brain or risk-override authority.

## When To Use
Use for OpenClaw boundary docs, assistant workflow planning, operator checklists, manual confirmation designs, and permission gate concepts.

## When Not To Use
Do not integrate OpenClaw yet or allow it to place orders, override risk, or bypass permissions.

## Required Inputs
- Operator workflow goal.
- Permission and risk constraints.
- Dashboard or alert context.

## Procedure
1. Define OpenClaw as assistant/operator layer only.
2. Route decisions through strategy, risk, permission, and audit systems.
3. Require manual confirmation only in future approved phases.
4. Document forbidden actions.

## Outputs
- Operator boundary docs, permission flow notes, and safety requirements.

## Safety Checks
- No autonomous live trading.
- No risk override.
- No hidden action path.

- "Plan OpenClaw operator workflow."
- "Define assistant permission boundaries."
